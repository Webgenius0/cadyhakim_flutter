## 📖 About

**Numynd** is a morning music app designed to make your mornings gentler and more energizing. Whether you want soft melodies to wake up slowly, uplifting tracks to get moving, or peaceful sounds to set your focus, Numynd keeps the music flowing so you can enjoy your morning without distractions.

---

## ✨ Features

- 🎵 **Morning-focused music** – tracks picked to match the mood of your morning
- 🔊 **Smooth audio player** – play, pause, seek, next and previous with ease
- 🔒 **Background playback** – music keeps playing when the app is minimized or the screen is locked
- 🎛️ **Lock screen & notification controls** – control playback without opening the app
- 🎨 **Clean, minimal UI** – distraction-free design that feels calm
- 📱 **Cross-platform** – works on both Android and iOS

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable)
- Android Studio / Xcode
- A connected device or emulator

### Installation

```bash
# Clone the repository
git clone https://github.com/zobayerdev/numynd.git

# Go to the project folder
cd numynd

# Install dependencies
flutter pub get

# Run the app
flutter run
```
